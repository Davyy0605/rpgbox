# RPGBox: plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Construir a primeira versão do RPGBox, um site com foco no celular para mestres de RPG guardarem, escreverem e consultarem rápido o material de suas campanhas.

**Architecture:** Django renderiza as páginas no servidor, com htmx para painéis e navegação parcial. Um pacote JS pequeno, gerado com esbuild e versionado no repositório, cuida do editor Tiptap, das sugestões `@`, do salvamento automático e do leitor de PDF. Textos ficam como JSON do Tiptap; links e busca são índices derivados, refeitos a cada salvamento.

**Tech Stack:** Python 3.12+, Django 5.2 LTS, htmx 2, Tiptap 2, pdf.js, esbuild, Pillow, django-storages[s3] (Cloudflare R2), dj-database-url, psycopg, whitenoise, gunicorn, pytest-django, pytest-playwright. Postgres (Neon) em produção; SQLite em desenvolvimento e nos testes.

**Spec:** `docs/superpowers/specs/2026-10-30-rpgbox-design.md`

## Global Constraints

- Interface em português do Brasil: `LANGUAGE_CODE = "pt-br"`, `TIME_ZONE = "America/Sao_Paulo"`. Identificadores do código em inglês.
- Celular primeiro: CSS escrito para 390 px e ampliado com `min-width`. Alvos de toque de 44 px ou mais. Campos com fonte de 16 px, para o iOS não dar zoom. Sem rolagem horizontal da página.
- Telas limpas: não acrescentar nada além do que a tarefa pede. Visual: fantasia sóbria e escura, sem tema claro.
- Toda view recebe dados por `get_campaign(user, id)` ou `get_record(user, id)` (Tarefa 2). Nenhuma consulta direta por id vindo da URL.
- Limite de 25 MB por arquivo. Imagens: até 1600 px no lado maior, WebP, qualidade 80. Miniaturas: 400 px. Original não é guardado.
- Um único nível de sub-abas.
- Links e incorporações só dentro da mesma campanha.
- Chaves e endereços só em variáveis de ambiente: `SECRET_KEY`, `DATABASE_URL`, `R2_BUCKET`, `R2_ENDPOINT_URL`, `R2_ACCESS_KEY_ID`, `R2_SECRET_ACCESS_KEY`, `ALLOWED_HOSTS`, `DEBUG`.
- JS de terceiros vai para o pacote local, nunca para CDN.
- `localStorage` sempre dentro de `try/catch`.

## Review Focus

1. **Foto enviada de um iPhone:** o Safari não gera WebP pelo canvas, então o navegador envia JPEG e o servidor converte. Pessoa espera ver a imagem salva, leve e em WebP (teste na Tarefa 7).
2. **Sinal caindo, ou site acordando, durante a escrita:** um salvamento pode levar 1 minuto ou falhar. Pessoa espera que nada se perca ao fechar e reabrir a página (teste na Tarefa 10).
3. **Referências que mudam de forma:** renomear, apagar, autoincorporar e A incorporar B que incorpora A. Pessoa espera nome atual, texto riscado e nenhum travamento (testes nas Tarefas 5 e 8).
4. **Arquivo errado ou disfarçado:** SVG renomeado para `.png`, imagem corrompida, 26 MB, HTML. Pessoa espera mensagem clara e nenhum arquivo perigoso aberto no site (teste na Tarefa 7).
5. **Mestre tentando abrir o id de outro mestre:** toda URL deve responder 404, inclusive miniaturas e exportação (teste parametrizado na Tarefa 15).

## Modelos (referência para todas as tarefas)

```python
# accounts
class User(AbstractUser): email = EmailField(unique=True)

# campaigns
class Campaign: owner(FK User), name, last_opened_at(null)
class RecordType: campaign(FK), name, position   # unique (campaign, name)
class FieldDef: record_type(FK), key(UUID str, default uuid4), label, kind("short"|"long"|"number"|"link"), position, removed(bool)
class TabDef: record_type(FK), parent(FK self, null), title, position, removed(bool)
class ListGroup: record_type(FK), name, position

# records
class Record: campaign(FK), record_type(FK), name, fields(JSON, default dict), group(FK ListGroup, null, SET_NULL),
              main_image(FK assets.Asset, null, SET_NULL), version(int, default 1), created_at, updated_at
class Tab: record(FK), tab_def(FK TabDef, null, SET_NULL), parent(FK self, null), title, position
class Block: tab(FK), kind("text"|"embed"), position, content(JSON, null), version(int, default 1),
             embed_record(FK Record, null, SET_NULL), embed_anchor(str, blank), embed_label(str, blank)

# indexing
class Link: source_record(FK), target_record(FK), target_anchor(str, blank), kind("mention"|"embed")
class SearchEntry: campaign(FK), record(FK), anchor(blank), title, title_norm, body_norm, kind("record"|"heading"|"text")

# assets
class Asset: id(UUID pk), owner(FK User), record(FK), tab(FK Tab, null), kind("image"|"document"), filename,
             content_type, size(int), key(str), thumb_key(blank), position, created_at
```

`Asset.tab` nulo significa Galeria do registro. Formato do texto: documento Tiptap (`{"type": "doc", "content": [...]}`). Menção: `{"type": "mention", "attrs": {"record": 12, "anchor": "", "label": "Kael"}}`. Título: `{"type": "heading", "attrs": {"level": 2, "anchor": "h-3f2a"}, "content": [...]}`.
